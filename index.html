AI / RAG 01 / 02

ArXiv Copilot Agentic Research Assistant

github/Arxiv-Research-Copilot
PythonFastAPIOpenSearchLiteLLMDoclingLangfuseLogfire

Built an end-to-end RAG-based agentic research assistant that automatically fetches, processes, indexes, and answers questions over ArXiv research papers.

  • Developed an agentic RAG pipeline for searching, fetching, summarizing, and answering questions from ArXiv papers.
  • Built an automated ingestion pipeline using Docling for PDF parsing, section-based chunking, embeddings, and indexing.
  • Implemented hybrid retrieval using BM25 + vector search to improve search relevance.
  • Designed multi-layer AI guardrails with rate limiting, regex filtering, and LLM-based safety checks.
  • Integrated LiteLLM for provider-agnostic LLM routing.
  • Added Langfuse and Logfire for tracing, observability, latency monitoring, and token usage tracking.
  • Optimized ingestion using parallel paper downloading and indexing.

AI / AGENTS 02 / 02

JobPilot AI JobMatch Agent

github/JobPilot-AI
PythonLangGraphLangfuse

Built an AI-powered job search agent that finds, ranks, and refines job listings and tailors resumes for selected roles.

  • Designed a multi-node LangGraph workflow for job fetching, ranking, query reformulation, resume tailoring, and validation.
  • Implemented an automatic query reformulation loop that re-runs the search when ranked results are weak.
  • Built a conditional entry router to support both job search and resume tailoring modes within a single graph.
  • Added a validation step to check tailored resume output before returning results.
  • Integrated Langfuse for end-to-end tracing and observability across graph nodes and LLM calls.
